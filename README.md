# B-Edificación Arquitectos | Landing Page Reformas Málaga

Landing page de alta conversión para **B-Edificación Arquitectos**, estudio de arquitectura y reformas integrales en Málaga.

## Características

- **Diseño responsive:** Optimizado para dispositivos móviles primero y escritorio.
- **Identidad visual:** Estilo *Warm Architectural Precision* con tipografías *Outfit* y *Manrope*.
- **Herramientas interactivas:**
  - Comparadores interactivos Antes / Después con control deslizante en tiempo real.
  - Calculadora de presupuesto interactiva por m² con 3 niveles de calidades.
  - Formulario de solicitud rápida con validación y respuesta en 24 horas.
  - Reproductor modal para testimonio en vídeo.
  - Acordeón de preguntas frecuentes (FAQ).
  - Barra de conversión fija en móviles para llamadas y WhatsApp directo.

## Despliegue en Vercel

Este proyecto está optimizado para su despliegue instantáneo como sitio web estático en [Vercel](https://vercel.com):

1. Conectar este repositorio (`javizx/reformas_malaga`) en el panel de Vercel.
2. Framework Preset: **Other** / **Static Site**.
3. Root Directory: `./`
4. Desplegar con un solo clic.
